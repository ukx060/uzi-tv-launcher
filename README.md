# Uzi TV Launcher
Lightweight Apple TV-style home screen for Android TV (target: Xiaomi Mi Box 4, Android 9).
- Blurred hero background from the focused app's banner, 16:9 rounded tiles, focus zoom/lift
- No background services, no network, no tracking
- Hold OK on a tile: move / hide / app info. Hold OK on the gear: show hidden apps, reset order.

Build: GitHub Actions → artifact `uzi-tv-launcher`.
Install: `adb install -r uzi-tv-launcher.apk`
